* **OpenCode V2 runs DAW's gates.** The OpenCode plugin now also speaks V2's interface, from the same file: a write a phase forbids is refused before it lands (through `write`, `edit`, `patch` and a namespaced id), a state forged behind it is reported in the result of the tool that follows, the user's turns are counted, and the bootstrap, the post-compaction reminder and the packaged skills reach the model as they do under V1. Under V2 every read-only DAW agent gets `edit: deny` and `shell: ask` in V2's `permissions` format, and a plugin install gains the `daw-module-verifier` it ships no file for. V1 loads and behaves as before. OpenCode's `apply_patch` now names its files to the gate, so a patch to product source in a phase that forbids it is refused where it was let through unjudged.
