* **A project's DAW settings live in `.daw/config.yml`, and `/daw-init` writes them.** The file is committed with the project and validated against `daw/config.schema.json`; when DAW starts in a repository without it, it offers `/daw-init`, and skipping it keeps today's flow. `spec-format: openspec` bridges a ticket to OpenSpec: the spec names one `openspec/changes/<name>` and writes only the how, its receipt seals that change too, and an edit to the change after approval drops the approval. `/daw-init` proposes OpenSpec where an `openspec/` folder exists and creates its layout when someone picks it without one. A `.daw/` holding only `config.yml` no longer reads as DAW copied in, and uninstalling keeps the file. The OpenSpec bridge is @mdiloreto's idea and code (#57).
